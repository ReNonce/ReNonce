# lib/

Container for ReNonce code boxes. Each box is self-contained with its own
toolchain and docs.

| Box | Contents |
|---|---|
| `desktop/` | Tauri desktop app (React frontend + Rust backend). See its `README.md`. |

More boxes (audit-tool sidecars, shared contracts) will land here as the
platform grows. Until then this folder holds the desktop app only — UI focus.
